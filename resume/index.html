03 / 工作方法

我如何把一个模糊问题变成可交付的研究结果

研究工作的难点不只是找到信息，而是知道为什么需要这些信息、如何判断它是否可靠，以及最后能为业务决策提供什么帮助。

01

定义问题

先确认核心问题与决策背景：进入新市场时，优先了解需求、竞品位置、渠道特点，还是购买障碍？

交付：研究问题清单与分析范围
02

寻找证据

根据目标选择来源：企业官方信息、电商平台、用户评价、行业报告与公开讨论；记录来源、时间、适用范围与局限。

交付：来源表与原始资料库
03

整理比较

把分散信息转成统一字段，用 Excel 建立价格、功能、定位、渠道与需求维度的比较。

交付：数据底表、竞品矩阵与初步发现
04

验证判断

对重要结论做跨来源对比，关注不同平台说法是否一致；冲突或信息不足处保留疑问，不把推测当事实。

交付：证据说明、关键判断与研究限制
05

形成建议

转化为结构化 PPT、Brief 或建议清单，回答：发现了什么？为什么重要？下一步验证或做什么？

交付：研究报告与优先级建议
INPUT → PROCESS → OUTPUT

输入信息：公开资料、用户反馈、渠道页面；研究加工：字段统一、交叉核验、比较与判断；业务输出：简报、矩阵、建议清单。

我的原则

从信息走向结论需要证据，从结论走向行动需要判断。我希望研究不仅能被阅读，也能被进一步讨论和使用。

05 / 研究思维

研究不是罗列信息，
而是把信息变成
可信的判断。

我坚持三个原则：先有问题再找资料；结论必须有依据；建议要考虑可行性。

原则一资料越多不代表越有效，要根据研究问题判断哪些信息必要
原则二重要判断尽量找到可追溯来源；口径冲突时明确差异，不强求一致
原则三机会之外还要考虑产品能力、渠道资源、用户认知、成本与风险
我的证据判断框架
行动建议结合业务目标的下一步
合理推断基于观察、仍需验证的解释
研究观察从若干证据中发现的规律或差异
已确认事实来源明确、口径可核对

我希望持续形成的不是对某个行业的固定答案，而是一种面对新业务、新市场和新问题时，可以反复使用的分析方法。

常见误区一

先堆资料再找问题：资料很多，但不知道要回答什么，最后变成信息罗列。

常见误区二

先有结论再找证据：只挑支持自己的资料，忽略相反的证据。

常见误区三

把研究发现直接当成商业结果：忽略产品能力、渠道、成本与执行条件。

所以我的做法
先写清楚要回答的问题，再决定要哪些证据，最后才给判断。

我的观察

产品特征不同，消费者寻找信息、比较方案和建立信任的方式也不同。研究 GTM 与市场沟通时，不能只比较价格或广告卖点，要把渠道和用户决策过程放在一起分析。

低客单 · 标准品

先解决“选哪个不出错”：参数、兼容、评价与价格透明。

内容型 · 创新硬件

先解决“我怎么用”：场景演示、实拍效果、创作者解释。

高客单 · 储能

先解决“我敢不敢买”：安全、售后、可靠性与本地服务。

08 / 研究项目 · 用户证据

如何从公开评价中理解用户真正关心什么

官方内容告诉我们品牌想强调什么；用户评价与讨论提供另一个角度：消费者实际在意什么、对哪些信息有疑虑。我把官方卖点与用户讨论结合，而不是直接把平台评分当成完整洞察。

Anker功能确定性
关注充电效率、兼容性、质量、可靠性与实际体验；用户在功能相近的产品之间如何建立购买信心。
买前疑虑：兼容吗？充得快吗？评价可信吗？
Insta360场景与结果
关注拍摄场景、画面效果、便携性与创作体验；实拍案例如何帮助潜在用户理解产品能解决什么问题。
买前疑虑：拍出来什么效果？剪辑难吗？值不值？
EcoFlow信任与风险
关注可靠性、使用场景、安全疑虑、售后与长期体验；高客单价产品购买前需要解释清楚哪些问题。
买前疑虑：安全吗？售后怎么样？真的能用吗？
我的验证方法

先整理官方宣传，再查看电商评价与公开讨论，按相同主题标签归类；对来源冲突保留证据差异，并说明样本局限。

研究局限

公开评论存在自选择、平台差异、样本偏差与商业合作影响；结论应作为进一步验证的基础，而不是总体消费者行为的精确统计。

证据链：官方说法 → 用户反馈 → 研究判断
官方卖点→电商评价 / 讨论→按主题归类→差异与共性→判断与待验证问题
一个反复出现的现象
官方说的是“我有什么”，用户想知道的是“这对我意味着什么”。
